# Town Forge 2D town art pass — 2026-10-23

Emberhold uses a new coordinated set of stone-and-timber building facades, amber windows,
muted roofs, world-aligned limestone paving, quieter turf, soft contact shadows, taller
border trees and drifting leaves/fireflies. Buildings and actors sort by their ground
position. NPC nameplates appear only at interaction range; the hero is 16% larger in
this town. Existing destinations, collisions, progression and saves are unchanged.

The 2D town's accidental 110px menu-page header is replaced by its MENU button, and
text on the native landscape page no longer receives the old portrait-world scaling.
Other menu pages retain their page headers. The source's centralized V-key switch is
now correctly recognized by the build-variant test (the old test expected four switches).

New artwork is original OpenAI image-generation output, generated with the built-in
image tool. Source: `art/town-polish/buildings-atlas.png`. Runtime crops:
`assets/town_polish/*.png`. Ten facades were generated; nine are Emberhold's existing
shops and amenities. The cottage is retained with the set; this pass adds no house node.
Eight scenery sprites are reused unchanged from Ashfall Survivors `game/assets/town/`
(tree_leafy, tree_autumn, tree_pine, prop_hedge, prop_lamp, town_fountain, prop_barrel,
prop_crates), original artwork supplied by Franklin, recorded in that project's
`game/ART-SOURCES.md` (Town art batch 1, 2026-10-12). Existing CraftPix/other assets
retain their original provenance. A generated scenery preview with unwanted background
haze was rejected and is not part of the game.

Building sprites were extracted by opaque connected-component bounds, with a 3px border,
without repainting pixels. Bilinear filtering handles downsampling; no WebGL1 NPOT
mipmaps are requested. Grass and paving are generated once by `town_2d_art.h` and
unloaded on shutdown. The 3D-only variant skips loading this new art.

Generation prompt: one transparent 5-column, 2-row sprite atlas; south-facing frontal
medieval RPG buildings with slightly elevated roof visibility; blacksmith, carpenter,
tailor, alchemist, town hall, provisioner, stable, healer chapel, bank and cottage;
consistent cool stone, aged oak, moss, muted slate/terracotta roofs, amber windows,
upper-left sunlight; complete isolated silhouettes, no people, labels, UI or scenery.

The other three towns retain their own themed building art. Wilderness, dungeon and
interior assets have not been restyled in this town pass.
